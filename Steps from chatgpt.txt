Below are the complete, clean, start-to-finish steps for running Kubernetes on your machine using K3s, deploying your WAR application, and enabling the Kubernetes Dashboard.
These are the exact steps we followed — rewritten cleanly so you can use them anytime.

🚀 FULL STEPS TO RUN KUBERNETES (K3s) + DEPLOY WAR + DASHBOARD
🟦 1. Install K3s (Lightweight Kubernetes)

Run:

curl -sfL https://get.k3s.io | sh -


Check K3s status:

systemctl status k3s


K3s should be running.

🟦 2. Setup kubectl by copying K3s kubeconfig

Because K3s stores kubeconfig in /etc/rancher/k3s/k3s.yaml (root-owned).

mkdir -p ~/.kube
sudo cat /etc/rancher/k3s/k3s.yaml > ~/.kube/config
chmod 600 ~/.kube/config
unset KUBECONFIG


Verify cluster connection:

kubectl get nodes


You should see:

NAME           STATUS   ROLES           AGE   VERSION
<hostname>     Ready    control-plane   ...

🟦 3. Build Your WAR Application Docker Image

Create a Dockerfile:

FROM tomcat:10.1-jdk17
COPY bank.war /usr/local/tomcat/webapps/bank.war


Build the image:

podman build -t bank-app:1.0 .

🟦 4. Import Podman Image into K3s (containerd)

Save the image:

podman save -o bank-app.tar bank-app:1.0


Import into K3s:

sudo k3s ctr images import bank-app.tar


Check:

sudo k3s ctr images ls | grep bank

🟦 5. Create Deployment for WAR App

Create bank-deployment.yaml:

apiVersion: apps/v1
kind: Deployment
metadata:
  name: bank-app
spec:
  replicas: 1
  selector:
    matchLabels:
      app: bank-app
  template:
    metadata:
      labels:
        app: bank-app
    spec:
      containers:
        - name: bank-container
          image: bank-app:1.0
          imagePullPolicy: IfNotPresent
          ports:
            - containerPort: 8080


Apply it:

kubectl apply -f bank-deployment.yaml


Check pods:

kubectl get pods

🟦 6. Expose Your App Using a NodePort Service

Create bank-service.yaml:

apiVersion: v1
kind: Service
metadata:
  name: bank-service
spec:
  type: NodePort
  selector:
    app: bank-app
  ports:
    - port: 8080
      targetPort: 8080
      nodePort: 30080


Apply:

kubectl apply -f bank-service.yaml


Check service:

kubectl get svc

🟦 7. Get WSL2 Node IP to Access App

Run:

hostname -I


Example:

172.22.89.29


Open your app:

http://172.22.89.29:30080/login

🟦 8. Install Kubernetes Dashboard

Install dashboard:

kubectl apply -f https://raw.githubusercontent.com/kubernetes/dashboard/v2.7.0/aio/deploy/recommended.yaml


Check:

kubectl get pods -n kubernetes-dashboard

🟦 9. Create Dashboard Admin User

Create file dashboard-admin.yaml:

apiVersion: v1
kind: ServiceAccount
metadata:
  name: admin-user
  namespace: kubernetes-dashboard

---
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRoleBinding
metadata:
  name: admin-user
roleRef:
  apiGroup: rbac.authorization.k8s.io
  kind: ClusterRole
  name: cluster-admin
subjects:
- kind: ServiceAccount
  name: admin-user
  namespace: kubernetes-dashboard


Apply it:

kubectl apply -f dashboard-admin.yaml

🟦 10. Expose Dashboard as NodePort

Create file dashboard-service.yaml:

apiVersion: v1
kind: Service
metadata:
  labels:
    k8s-app: kubernetes-dashboard
  name: kubernetes-dashboard
  namespace: kubernetes-dashboard
spec:
  type: NodePort
  selector:
    k8s-app: kubernetes-dashboard
  ports:
    - port: 443
      targetPort: 8443
      protocol: TCP
      nodePort: 30001


Apply:

kubectl apply -f dashboard-service.yaml


Verify:

kubectl get svc -n kubernetes-dashboard


Expected:

443:30001/TCP

🟦 11. Open Dashboard

Open in browser:

https://172.22.89.29:30001


Click Advanced → Proceed (self-signed certificate).

🟦 12. Get Login Token

Run:

kubectl -n kubernetes-dashboard create token admin-user


Copy token → paste into Dashboard login page.

🎉 Your Kubernetes Cluster is Fully Running

You're now able to:

✔ Run K3s Kubernetes cluster
✔ Deploy WAR applications with Tomcat
✔ Expose them with NodePort
✔ Access from browser
✔ Use Admin Dashboard
✔ Inspect pods, logs, deployments
